# Zettelgarden Product Overview

## What is Zettelgarden?

Zettelgarden is a human-centric, open-source personal knowledge management system built on proven zettelkasten principles. It combines the time-tested methodology of interconnected note-taking with modern AI capabilities to help knowledge workers build understanding, not just store information.

## Target Audience

**Primary Users:**
- Researchers and academics
- Knowledge workers and consultants
- Students and lifelong learners
- Writers and content creators
- Anyone who works with complex information

**User Personas:**
- **The Academic Researcher**: Needs to organize literature, track citations, and discover connections between studies
- **The Strategic Consultant**: Must synthesize client information, industry insights, and frameworks
- **The Content Creator**: Wants to build a knowledge base that feeds into articles, courses, and content
- **The Lifelong Learner**: Seeks to retain and connect knowledge across multiple domains

## Key Features

### Core Features (Free Tier)
- **Atomic Notes (Cards)**: Markdown-supported notes with unique identifiers
- **Bidirectional Linking**: Connect ideas across your knowledge base
- **Task Management**: Integrated todo system with scheduling and priorities
- **File Attachments**: Upload and organize supporting documents
- **Basic Search**: Text-based search across all content
- **Starred Content**: Bookmark important cards and searches
- **Templates**: Reusable card templates with variables

### PRO Features ($10/month, $100/year)
- **Vector Search**: Semantic search using embeddings
- **Entity Recognition**: Automatic extraction and linking of people, places, concepts
- **Content Analysis**: AI-powered summaries and insights
- **Advanced Facts**: Structured data extraction and management
- **Memory System**: Personal knowledge retention and recall

### Technical Features
- **Self-Hostable**: Complete data ownership and privacy
- **Web-Based**: Access from any browser, any device
- **Real-time Sync**: Live updates across sessions
- **API Access**: Programmatic integration capabilities
- **Keyboard Shortcuts**: Efficient power-user workflows

## Technical Architecture

### Modern Stack
- **Frontend**: React/TypeScript with Vite
- **Backend**: Go with PostgreSQL + pgvector
- **Search**: Typesense with vector embeddings
- **AI**: OpenAI-compatible API integration

### Deployment Options
- **Cloud Hosted**: Managed service at zettelgarden.com
- **Self-Hosted**: Docker deployment on your infrastructure
- **Hybrid**: Cloud features with local data storage
